# Prayer Activate

## Do you miss the old Piety noise instead of the bonk after unlocking Zeal? This is for you.

Prayer Activate changes the sounds played when prayers are activated. For now,
it only changes the Zeal activation sound to the Piety activation sound; all
other prayer activation sounds remain unchanged.

## Installation

Once Prayer Activate is available on the RuneLite Plugin Hub:

1. Open RuneLite's **Plugin Hub** from the sidebar.
2. Search for **Prayer Activate** and install it.
3. Find **Prayer Activate** in the installed plugins list and enable it.
